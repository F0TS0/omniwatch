# UI specification

The visual language is an archival institutional interface: dark olive-neutral surfaces, thin grey-green borders, muted copy, serif display type, and monospaced data labels.

The landing page makes the preserved particle face central. The simulation reduces it to a contextual panel beside the signal register. It reacts only through subtle movement during processing, threshold crossing, and authorisation.

Timeline rows are released progressively. Future rows remain sealed. The 70% threshold persists between the 45% and 71% signals. No alarm, flashing warning, game meter, or glitch treatment is used.

All interactive controls have visible keyboard focus, use native buttons and links, and reduced-motion preferences sharply reduce CSS animation; the face also retains its existing reduced-motion behavior.
